1. PROJECT MISSION STATEMENT
--------------------------------------------------------------------------------
Planify is a premier "Mission Control" ecosystem designed for high-stakes task 
management. It combines a futuristic Glassmorphism aesthetic with a robust 
FastAPI/React architecture to provide a seamless, secure, and visually 
stunning strategic planning experience.

2. CORE FUNCTIONALITIES & USER EXPERIENCE
--------------------------------------------------------------------------------
- Mission Deployment: Create tasks with titles, detailed strategic notes, 
  and neon-coded priority levels (Critical, Medium, Low).
- Real-time Analytics Dashboard: Instant feedback on mission counts (Total, 
  Active, Concluded, Critical).
- Intelligence Logs (Mission Debrief): Dynamic completion notes that sync 
  instantly to the backend as the user records their victory.
- Strategic Sorting: Global filters to toggle between operational phases 
  (Active missions vs. Concluded intel).
- Terminus Protocol: Simple, fast deletion for neutralized objectives.
- Glassmorphism Design: Custom UI system featuring backdrop blurs, 
  radial gradients, and fluid micro-animations.

3. TECHNOLOGY STACK (THE "INTELLIGENCE CORE")
--------------------------------------------------------------------------------
FRONTEND CORE:
- React 19: Component-based UI logic and state management.
- Vite: High-speed bundling and development orchestration.
- Vanilla CSS: A custom design system built from the ground up (no generic UI kits).
- Google Fonts: "Outfit" typography for a premium, aerospace feel.

BACKEND CORE:
- FastAPI (Python): High-performance asynchronous REST API.
- SQLAlchemy: Object-Relational Mapping for database communication.
- Pydantic: Strict data validation and serialization.
- Uvicorn: The lightning-fast ASGI server deployment.

PERSISTENCE & DEPLOYMENT:
- SQLite: Relational database engine for local persistence.
- Docker & Docker Compose: Full service orchestration and containerization.

5. LOGIC FLOW: A MISSION'S LIFECYCLE
--------------------------------------------------------------------------------
1. CONFIGURATION: The system initializes the SQLite database (tasks.db) and 
   sets up the RESTful endpoints.
2. DEPLOYMENT (POST): The user enters mission intel in the "Plan your next move" 
   panel. The frontend validates the input and sends a JSON payload to the 
   FastAPI `/tasks` endpoint.
3. PERSISTENCE: The backend receives the payload, validates it via Pydantic 
   schemas, and saves the mission to SQLite using SQLAlchemy.
4. ANALYTICS: The dashboard's stats bar updates instantly to reflect the new 
   mission count and priority density.
5. TRANSITION (PATCH): When a mission is marked as Concluded, its status 
   field is updated in the DB via an airborne PATCH request.
6. DEBRIEF: The completion note input appears. Every note recorded is synced 
   back to the backend on "Blur" or "Enter", ensuring no data is lost during 
   the debriefing process.
7. NEUTRALIZATION (DELETE): A DELETE request is sent to the terminus endpoint, 
   removing the mission from the operational grid forever.
